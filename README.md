# Gym ERP: 스마트 헬스장 통합 관리 시스템

> 헬스장 운영에 필요한 판매·재고·회원·근태 정보를 통합 관리하고,데이터 기반 의사결정과 운영 효율화를 지원하는 스마트 ERP

<br>

* **개발 기간:** 2025.10.13 ~ 2025.11.12
* **개발 인원:** 총 9명 (기능 단위 Full-Stack 협업 방식)
  
<br>

## 기술 스택 (Tech Stack)

| 구분 | 기술 |
| :-- | :-- |
| **Backend** | Java, Spring Boot, REST API, Swagger |
| **Frontend** | React, HTML5, JavaScript, CSS3 |
| **DB & Infra** | Oracle, Docker, Nginx, AWS |
| **협업툴** | Git, GitHub, Notion |

<br>

<br>

## 담당 영역 : 실물상품 판매·매출 도메인 풀스택 개발 (개인 배포 포함)


* 판매 발생 시 상품·재고 연계를 통한 판매 내역 자동 생성 백엔드 로직 구현
* 날짜·직원·상품 조건 기반 판매 내역 조회 API 및 페이징 처리, React 화면 연동
* 모달 기반 판매 등록/조회 CRUD 구현 (수량·금액 자동 계산, 재고 초과/0 이하 판매 백엔드 검증)
* 공통 상품·직원 검색/선택 모듈 구현 (실시간 필터링, 선택 즉시 반영)
* Docker · Nginx · AWS EC2 환경 개인 배포 및 운영 경험
